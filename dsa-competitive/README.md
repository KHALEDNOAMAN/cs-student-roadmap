# DSA & Competitive Programming Track (16-Week Plan)

Sharpen your problem-solving skills and prepare for top-tier tech interviews.

## Roadmap (10 LeetCode problems each week)

- **Week 1-2:** Arrays, strings, sorting, and two pointers
- **Week 3-4:** Linked lists, stacks, queues, and sliding window
- **Week 5-6:** Trees, Binary Search Trees (BST), heaps/priority queues
- **Week 7-8:** Graphs (BFS, DFS, shortest path algorithms like Dijkstra)
- **Week 9-10:** Dynamic programming (1D, 2D, knapsack, LCS)
- **Week 11-12:** Backtracking, greedy algorithms, divide & conquer
- **Week 13-14:** Advanced topics (Segment Tree, Trie, Union-Find/Disjoint Set)
- **Week 15-16:** Mock interviews, timed contests, and final review
