# Mobile Development Track (20-Week Plan)

Master cross-platform mobile development using Flutter and Dart.

## Roadmap

- **Week 1-3:** Dart & Flutter basics (Syntax, OOP, Environment Setup)
- **Week 4-5:** UI design & widgets (Layouts, Material/Cupertino, Styling)
- **Week 6-7:** State management (Provider, Riverpod, Bloc)
- **Week 8-9:** API integration (HTTP requests, JSON parsing)
- **Week 10-11:** Local storage & SQLite (Shared Preferences, SQFlite)
- **Week 12-13:** Firebase (Auth, Firestore, Cloud Messaging)
- **Week 14-15:** Platform-specific features (Camera, Location, Permissions)
- **Week 16-17:** Testing & debugging (Unit/Widget/Integration Testing)
- **Week 18-20:** Capstone & Publishing

### Capstone Project
**Social Media App with Real-Time Chat**
Develop a fully functional social media app with Firebase integration, allowing users to post, like, and chat in real-time. Publish the final app to the Google Play Store.
