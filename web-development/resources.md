# Web Development Resources

A curated list of the best free resources for mastering web development.

## 🎓 Comprehensive Curriculums
- **[The Odin Project](https://www.theodinproject.com/)**: One of the most highly regarded open-source curriculums. Project-heavy and teaches you to think like a developer.
- **[Full Stack Open](https://fullstackopen.com/en/)**: Created by the University of Helsinki. Excellent for learning modern React, Node.js, GraphQL, and TypeScript.
- **[freeCodeCamp](https://www.freecodecamp.org/)**: Interactive learning platform covering everything from basic HTML to advanced backend APIs.

## 📖 Documentation & References
- **[MDN Web Docs](https://developer.mozilla.org/)**: The ultimate reference for HTML, CSS, and JavaScript.
- **[JavaScript.info](https://javascript.info/)**: A modern, deep-dive tutorial into JavaScript.
- **[React Documentation](https://react.dev/)**: The newly rewritten React docs are incredible and feature interactive sandboxes.

## 📺 YouTube Channels
- **[Traversy Media](https://www.youtube.com/c/TraversyMedia)**: Great crash courses on almost every web technology imaginable.
- **[Web Dev Simplified](https://www.youtube.com/c/WebDevSimplified)**: Excellent channel for breaking down complex concepts into easy-to-understand videos.
- **[Kevin Powell](https://www.youtube.com/kepowob)**: The absolute best channel for mastering CSS.
- **[Fireship](https://www.youtube.com/c/Fireship)**: High-energy, fast-paced videos on modern web development concepts (famous for "100 Seconds of Code").

## 🛠️ Tools & Practice
- **[Frontend Mentor](https://www.frontendmentor.io/)**: Provides professional designs (Figma/Sketch) for you to build and practice your frontend skills.
- **[LeetCode](https://leetcode.com/) / [Codewars](https://www.codewars.com/)**: Good for practicing JavaScript algorithms and data structures.
- **[Figma](https://www.figma.com/)**: Free design tool to plan your UI before coding.

## 📚 Free Books
- **[Eloquent JavaScript](https://eloquentjavascript.net/)**: A deep dive into JS. Not for the faint of heart, but highly rewarding.
- **[You Don't Know JS](https://github.com/getify/You-Dont-Know-JS)**: A book series that dives deep into the core mechanisms of the JavaScript language.

## 🌐 Communities
- **Discord**: The Odin Project and freeCodeCamp have massive, incredibly helpful Discord servers.
- **Reddit**: [/r/webdev](https://www.reddit.com/r/webdev/), [/r/reactjs](https://www.reddit.com/r/reactjs/), [/r/learnprogramming](https://www.reddit.com/r/learnprogramming/)
