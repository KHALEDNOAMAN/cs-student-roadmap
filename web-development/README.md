# Web Development Track

Welcome to the Web Development track! This comprehensive 24-week plan will take you from the basics of internet architecture to building fully functional, full-stack scalable web applications.

## 📅 24-Week Plan

### Week 1-3: HTML & CSS Fundamentals
- **Topics**: HTML5 semantics, forms, accessibility. CSS3 selectors, Box Model, Flexbox, CSS Grid, responsive design (media queries).
- **Resources**: The Odin Project (Foundations), MDN Web Docs.
- **Project**: Build a responsive portfolio website and a clone of the Google homepage.

### Week 4-6: JavaScript Deep Dive
- **Topics**: Variables, data types, functions, DOM manipulation, event listeners, ES6+ features (arrow functions, destructuring, template literals), asynchronous JS (Promises, async/await).
- **Resources**: JavaScript.info, Eloquent JavaScript (book).
- **Project**: Interactive to-do list and a weather app using a public API.

### Week 7-9: React.js
- **Topics**: Components, JSX, props, state (useState, useEffect), handling events, conditional rendering, React Router.
- **Resources**: React Official Documentation, freeCodeCamp React course.
- **Project**: Movie database app fetching from TMDB API, simple blog frontend.

### Week 10-11: Node.js & Express
- **Topics**: Backend concepts, RESTful architecture, creating servers, routing, middleware, handling HTTP requests/responses.
- **Resources**: Full Stack Open (University of Helsinki).
- **Project**: Build a REST API for a task management application.

### Week 12-13: Databases (MongoDB, PostgreSQL)
- **Topics**: Relational vs NoSQL databases. SQL basics, schema design. Mongoose for MongoDB, Prisma or TypeORM for PostgreSQL.
- **Resources**: MongoDB University, PostgreSQL official tutorial.
- **Project**: Connect your task API to a real database and perform CRUD operations.

### Week 14-15: REST API Design
- **Topics**: API versioning, pagination, filtering, error handling, status codes.
- **Resources**: Microsoft REST API Guidelines.
- **Project**: Refactor your backend to production-grade standards.

### Week 16-17: Authentication & Security
- **Topics**: JWT (JSON Web Tokens), cookies, sessions, OAuth (Google/GitHub login), password hashing (bcrypt), CORS, basic OWASP top 10 (XSS, CSRF).
- **Resources**: Web Security Academy (PortSwigger).
- **Project**: Add user registration, login, and protected routes to your application.

### Week 18-19: TypeScript
- **Topics**: Static typing, interfaces, types, generics, migrating a JS project to TS.
- **Resources**: TypeScript Handbook, Matt Pocock's TS tutorials.
- **Project**: Convert a previous React or Node project entirely into TypeScript.

### Week 20-21: Next.js
- **Topics**: Server-Side Rendering (SSR), Static Site Generation (SSG), file-based routing, API routes, Next.js image optimization.
- **Resources**: Next.js Learn (Official tutorial).
- **Project**: Build a SEO-friendly blog or marketing site.

### Week 22-24: Full-Stack Capstone
- **Topics**: Deployment (Vercel, Render), CI/CD basics, testing (Jest, Cypress).
- **Capstone Project**: **E-commerce Platform**. Build a complete e-commerce store with user authentication, product search/filtering, shopping cart, and Stripe payment integration. Deploy it live.
