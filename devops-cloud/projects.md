# 10 DevOps & Cloud Projects

1. **Linux Web Server setup**: Configure a Nginx web server with reverse proxy manually. (Beginner)
2. **Bash Backup Script**: Write a script to automate database and file backups. (Beginner)
3. **Containerized Web App**: Dockerize a simple Node.js or Python application. (Beginner)
4. **CI/CD Pipeline**: Setup a Jenkins pipeline to build and test a Java application. (Intermediate)
5. **Static Site on S3**: Host a React application on AWS S3 with CloudFront CDN. (Intermediate)
6. **Terraform Infrastructure**: Use Terraform to spin up a VPC, EC2 instance, and RDS database. (Intermediate)
7. **Ansible Configuration**: Automate the provisioning of multiple web servers using Ansible. (Advanced)
8. **Kubernetes Cluster**: Deploy a highly available WordPress site on Kubernetes. (Advanced)
9. **Monitoring Stack**: Setup Prometheus and Grafana to monitor server CPU/Memory metrics. (Advanced)
10. **Microservices K8s Deployment**: The capstone project, encompassing all learned tools. (Advanced)
