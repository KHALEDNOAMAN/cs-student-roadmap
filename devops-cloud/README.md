# DevOps & Cloud Track (16-Week Plan)

Bridge the gap between development and operations. Learn to automate, deploy, and scale applications in the cloud.

## Roadmap

- **Week 1-2:** Linux administration & shell scripting
- **Week 3-4:** Docker (Containers, Images, Docker Compose)
- **Week 5-6:** Kubernetes (Pods, Services, Deployments, ConfigMaps)
- **Week 7-8:** CI/CD pipelines (GitHub Actions, Jenkins, GitLab CI)
- **Week 9-10:** AWS/GCP fundamentals (EC2/Compute Engine, S3/Cloud Storage, VPC)
- **Week 11-12:** Infrastructure as Code (Terraform, Ansible basics)
- **Week 13-14:** Monitoring & Observability (Prometheus, Grafana, ELK stack)
- **Week 15-16:** Capstone Project

### Capstone Project
**Deploy a Microservices App on Kubernetes**
Take a multi-tier microservices application, containerize it with Docker, create an automated CI/CD pipeline using GitHub Actions, provision cloud infrastructure with Terraform, and deploy the application on a managed Kubernetes cluster (EKS/GKE) with Prometheus monitoring.
