# Embedded Systems Track

Welcome to the Embedded Systems track! This 20-week plan will take you from basic C programming to building an advanced smart home system using RTOS and IoT concepts.

## 📅 20-Week Plan

### Week 1-2: C Programming Fundamentals
- **Topics**: Data types, variables, control flow (if/else, loops), functions, arrays, and basic pointers.
- **Resources**: C Programming tutorials on YouTube, freeCodeCamp C course.
- **Mini-Project**: Command-line calculator and a basic text-based adventure game.

### Week 3-4: Digital Electronics Basics
- **Topics**: Logic gates, Boolean algebra, flip-flops, registers, number systems (binary, hex).
- **Resources**: Ben Eater's digital logic series, MIT OCW circuits.
- **Mini-Project**: Simulate a 4-bit adder in Tinkercad or Proteus.

### Week 5-6: Microcontroller Basics (Arduino)
- **Topics**: Introduction to MCU architecture, setup Arduino IDE, basic GPIO operations.
- **Resources**: Arduino official documentation, Paul McWhorter's Arduino tutorials.
- **Mini-Project**: Complex LED blinking patterns, reading push buttons.

### Week 7-8: Advanced Peripherals (GPIO, ADC, PWM, Timers)
- **Topics**: Analog-to-Digital Conversion, Pulse Width Modulation, hardware timers, interrupts.
- **Resources**: Data sheets for ATmega328p, microcontroller peripheral guides.
- **Mini-Project**: Light dimmer using a potentiometer (ADC) and an LED (PWM).

### Week 9-10: Communication Protocols (UART, SPI, I2C)
- **Topics**: Serial vs parallel communication, synchronous vs asynchronous, protocol implementation.
- **Resources**: SparkFun tutorials on SPI and I2C.
- **Mini-Project**: Interface an I2C OLED display and an SPI SD card module.

### Week 11-12: ESP32 & WiFi/Bluetooth
- **Topics**: ESP32 architecture, wireless communication, basic networking, web servers on ESP32.
- **Resources**: Random Nerd Tutorials (ESP32 section).
- **Mini-Project**: Build a simple local web server to toggle LEDs from your phone.

### Week 13-14: Real-Time Operating Systems (FreeRTOS Basics)
- **Topics**: Multitasking, tasks, queues, semaphores, mutexes, scheduling.
- **Resources**: Digi-Key FreeRTOS tutorial series.
- **Mini-Project**: Multi-tasking system to read a sensor, update a display, and blink a heartbeat LED concurrently.

### Week 15-16: Sensor Integration & Motor Control
- **Topics**: Interfacing IMUs (accelerometers/gyroscopes), temperature sensors, controlling DC and stepper motors, H-bridges.
- **Resources**: DroneBot Workshop videos.
- **Mini-Project**: Build a simple line-following robot chassis.

### Week 17-18: PCB Design Basics
- **Topics**: Schematic capture, PCB layout, routing, Gerber files.
- **Resources**: Phil's Lab KiCad tutorials.
- **Mini-Project**: Design a custom PCB shield for your ESP32 or Arduino.

### Week 19-20: Capstone Project
- **Topics**: System integration, project planning, debugging, and testing.
- **Capstone Project**: **Smart Home System**. Create an IoT system using an ESP32, MQTT protocol, various sensors (temp, motion), and control it via a mobile app or web dashboard.
