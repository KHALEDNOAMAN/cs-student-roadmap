# Embedded Systems Projects

Here are 10 projects ranging from beginner to advanced to help you practice your embedded systems skills.

## 1. LED Blink Patterns (Beginner)
- **Description**: Control multiple LEDs to create various patterns (chaser, Knight Rider, breathing effect).
- **Components Needed**: Microcontroller (e.g., Arduino), LEDs, resistors, breadboard.
- **Skills Learned**: Basic GPIO output, delays, loops.
- **Estimated Time**: 2 hours

## 2. Smart Traffic Light System (Beginner)
- **Description**: Simulate a 4-way intersection traffic light with pedestrian crossing buttons.
- **Components Needed**: Microcontroller, colored LEDs, push buttons.
- **Skills Learned**: State machines, GPIO input/output, simple logic.
- **Estimated Time**: 4 hours

## 3. Digital Temperature Monitor (Beginner-Intermediate)
- **Description**: Read temperature data and display it on an LCD or OLED screen. Add an alarm if the temperature exceeds a threshold.
- **Components Needed**: Microcontroller, DHT11/LM35 sensor, I2C Display, buzzer.
- **Skills Learned**: ADC or digital sensor interfacing, I2C protocol.
- **Estimated Time**: 1 week

## 4. Line Follower Robot (Intermediate)
- **Description**: A two-wheel robot that autonomously follows a black line on a white surface.
- **Components Needed**: Microcontroller, IR sensor array, L298N motor driver, DC motors, chassis.
- **Skills Learned**: Motor control, PWM, basic control algorithms (bang-bang or PID).
- **Estimated Time**: 2 weeks

## 5. Local Weather Station (Intermediate)
- **Description**: Collect environmental data (temp, humidity, pressure) and log it to an SD card.
- **Components Needed**: Microcontroller, BME280 sensor, SD card module, RTC module.
- **Skills Learned**: SPI, I2C, file systems (FAT32), real-time clocks.
- **Estimated Time**: 2 weeks

## 6. IoT Home Automation Hub (Intermediate-Advanced)
- **Description**: Use an ESP32 to host a web server that controls home appliances via relays.
- **Components Needed**: ESP32, Relay modules, jumper wires, a device to control (e.g., lamp).
- **Skills Learned**: WiFi networking, HTTP, HTML/CSS for web dashboard, GPIO.
- **Estimated Time**: 3 weeks

## 7. Basic Drone Controller (Advanced)
- **Description**: Build a flight controller reading IMU data to stabilize a quadcopter.
- **Components Needed**: Microcontroller with fast clock, MPU6050 (IMU), ESCs, brushless motors.
- **Skills Learned**: Sensor fusion, PID control loops, fast PWM generation.
- **Estimated Time**: 4-6 weeks

## 8. OBD-II Car Data Reader (Advanced)
- **Description**: Interface with a car's OBD-II port to read engine RPM, speed, and diagnostics.
- **Components Needed**: ESP32/Arduino, CAN bus transceiver module (MCP2515), OLED display.
- **Skills Learned**: CAN bus protocol, automotive diagnostics parsing.
- **Estimated Time**: 4 weeks

## 9. Custom Dev Board / PCB (Advanced)
- **Description**: Design your own Arduino-compatible board from schematic to physical PCB.
- **Components Needed**: KiCad/Altium, ATmega328p bare chip, passive components, PCB manufacturer (e.g., JLCPCB).
- **Skills Learned**: Schematic design, PCB layout, component sourcing, soldering.
- **Estimated Time**: 3-4 weeks

## 10. RTOS-based Multitask System (Advanced)
- **Description**: A comprehensive system running FreeRTOS handling sensor polling, display updates, and wireless communication concurrently.
- **Components Needed**: ESP32 or STM32, various sensors, display.
- **Skills Learned**: RTOS task management, queues, semaphores, race condition prevention, embedded system architecture.
- **Estimated Time**: 4 weeks
