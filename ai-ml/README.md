# AI & Machine Learning Track (24-Week Plan)

Welcome to the AI & Machine Learning track! This comprehensive roadmap will take you from the basics of data science to deploying complete ML models.

## Roadmap

- **Week 1-3:** Python for data science (NumPy, Pandas, Matplotlib, Seaborn)
- **Week 4-5:** Statistics & probability (Distributions, Hypothesis Testing, Bayes)
- **Week 6-8:** Machine learning fundamentals (scikit-learn, Regression, Classification, Clustering)
- **Week 9-10:** Deep learning basics (PyTorch/TensorFlow, Neural Networks basics)
- **Week 11-12:** Computer vision (CNNs, Image Classification, Object Detection)
- **Week 13-14:** NLP basics (Text Processing, Embeddings, RNNs/LSTMs)
- **Week 15-16:** Transformers & LLMs (Attention Mechanism, Hugging Face, BERT, GPT)
- **Week 17-18:** Reinforcement learning (Q-Learning, Policy Gradients)
- **Week 19-20:** MLOps & deployment (Docker, FastAPI, MLflow)
- **Week 21-24:** Capstone Project

### Capstone Project
**AI-powered image classification app deployed on cloud**
Build an end-to-end application where users can upload an image, and a deployed PyTorch model identifies the object in real-time, hosted on AWS or GCP.
