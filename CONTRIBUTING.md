# Contributing to CS Student Roadmap

First off, thank you for considering contributing to the CS Student Roadmap! It's people like you that make this community such a great place to learn.

## How Can I Contribute?

### 1. Improve Existing Tracks
- **Fix errors or typos**: Found a broken link or a typo? Open a pull request!
- **Add new resources**: Know a great free course, book, or YouTube channel? Add it to the relevant `resources.md` file.
- **Propose new projects**: Have an idea for a cool project? Add it to the appropriate `projects.md` file with a description, difficulty level, and required skills.
- **Enhance weekly plans**: If you feel a topic is missing or should be reorganized in a `README.md` plan, suggest a change.

### 2. Add New Tracks
Want to create a completely new track (e.g., Mobile Development, Data Science)?
1. Create a new folder with the track name (lowercase, hyphenated).
2. Inside the folder, create `README.md`, `projects.md`, and `resources.md`.
3. Follow the structure of existing tracks (e.g., Web Development or Embedded Systems).
4. Update the main `README.md` to include your new track.

## Submitting Changes
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-feature`).
3. Make your changes and commit them (`git commit -m 'Add some amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

Please ensure your pull request description clearly describes the problem and solution. Include the relevant issue number if applicable.
