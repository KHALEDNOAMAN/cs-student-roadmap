# Cybersecurity Track (20-Week Plan)

Dive deep into the world of cybersecurity, learning how to secure systems, find vulnerabilities, and analyze malware.

## Roadmap

- **Week 1-2:** Linux fundamentals & networking (Bash, OSI model, TCP/IP)
- **Week 3-4:** Network security & protocols (Firewalls, IDS/IPS, Wireshark, Nmap)
- **Week 5-6:** Web security (OWASP Top 10, SQLi, XSS, CSRF)
- **Week 7-8:** Cryptography (Symmetric/Asymmetric encryption, Hashing, PKI)
- **Week 9-10:** Penetration testing basics (Metasploit, Reconnaissance, Exploitation)
- **Week 11-12:** Reverse engineering (Assembly basics, Ghidra, IDA)
- **Week 13-14:** Digital forensics (Disk/Memory forensics, Autopsy)
- **Week 15-16:** Cloud security (AWS security, IAM, CloudTrail)
- **Week 17-18:** Malware analysis (Static/Dynamic analysis, Sandboxing)
- **Week 19-20:** CTF challenges & Capstone

### Capstone Project
**Vulnerability Scanner**
Build a custom python-based vulnerability scanner that takes an IP/Domain, enumerates open ports, identifies services, and cross-references with a CVE database.
