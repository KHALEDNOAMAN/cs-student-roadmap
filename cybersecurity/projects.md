# 10 Cybersecurity Projects

1. **Keylogger**: Build a basic keylogger for educational purposes. (Beginner)
2. **Packet Sniffer**: Create a tool to capture and analyze network packets using Scapy. (Beginner)
3. **Password Cracker**: Develop a script to crack hashes using dictionary attacks. (Beginner)
4. **Vulnerable Web App**: Build a small web app with intentional OWASP vulnerabilities. (Intermediate)
5. **IDS/IPS Setup**: Deploy and configure Snort on a virtual network. (Intermediate)
6. **Port Scanner**: Build a concurrent port scanner using Python/Go. (Intermediate)
7. **Malware Sandbox**: Set up a Cuckoo sandbox environment for safe analysis. (Advanced)
8. **Ransomware Simulator**: Create a program that encrypts/decrypts specific files. (Advanced)
9. **Phishing Tool**: Develop an educational phishing template generator. (Advanced)
10. **Custom Vulnerability Scanner**: The capstone project, integrating recon and CVE lookups. (Advanced)
